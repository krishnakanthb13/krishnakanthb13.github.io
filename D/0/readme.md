# D/0 — Knowledge Vault

## Why This Exists

This directory is a living, growing knowledge vault. As knowledge is earned—through research, reflection, and deep study—it gets dropped in here as self-contained topic folders. Each folder is a complete "module" on a single subject, pairing a long-form written report with interactive HTML visualizations so the material can be both read and explored.

The goal is simple: **knowing is cheap, structure is everything.** A fact picked up from a sentence decays; a curated, navigable vault compounds.

## How It's Organized

- Each **subfolder** = one topic, earned and curated.
- `readme.md` — the long-form essay / research report (the written knowledge).
- `index.html` — the primary interactive visualization of that topic.
- `0.html`, `1.html`, ... — alternate or companion interactive variants (light themes, simulators, quizzes, etc.), when present.
