Usage Limits Hardcoded

On top of monthly credits, every subscription plan has two rolling windows — a 5-hour limit and a weekly limit — that smooth out bursts so a single session can't drain the whole month. GOAT uses 20% / 50% of its usage pool; all others use 30% / 60%. Limits are measured in credit value, not request count.

Rolling windows open on the first request after the previous one elapses and reset exactly one window-length later. Top-up and pay-as-you-go credits are never throttled — they spend first while you're over a window. Run /usage in the CLI for live 5-hour and weekly meters.

⚡ Usage Beyond Limits

Rolling windows throttle only your included monthly credits. On-demand top-up credits are never throttled.

  • While over a window, Command Code spends your on-demand credits first
  • Buy extra credits any time with /extra — they roll over and never expire
  • Free models (Laguna S 2.1) keep working even with zero balance
  • Run /usage in the CLI for live 5-hour & weekly meters

📉 Why Some Models Have Lower Allowances

Command Code negotiates capacity and runs 95–98% cache hit rates — savings come back to you as bigger credit allowances.

  • Models with negotiated deals get boosted allowances (up to full $70 on GOAT)
  • New models start at 2× credits ($20 on GOAT) until a deal is landed
  • Allowances update automatically the moment a deal starts — no codes, no toggles
  • Deals stack on top of your plan's credit multiplier, so savings compound
